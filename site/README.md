# Irina Dinga · сайт

Статический сайт без сборки и зависимостей. Деплой на Vercel: `vercel.json` в корне репозитория отдаёт папку `site/`.

## Что где менять

| Что | Где |
|---|---|
| Цены и длительность услуг | `js/config.js` → `services[].price` / `duration` (пока `null` → «Precio tras consulta») |
| Телефон WhatsApp, часы, ссылки на соцсети | `js/config.js` |
| Тексты ES / EN / RU, отзывы, оттенки, до/после, хронология | `js/content.js` |
| Цвета, шрифты, вёрстка | `css/styles.css` (токены в `:root`) |
| Фото / видео | `assets/img`, `assets/video` (webp 1080 px + `-sm` 640 px) |

## Запись

Демо: клиентка выбирает услугу, день и время → открывается WhatsApp `+34 623 920 999` с готовым сообщением на её языке. Слоты считаются из `hours` в конфиге (воскресенье закрыто, последняя запись за 90 мин до закрытия, минимум 3 ч до визита). Чтобы подключить реальный календарь, замените `window.SITE_BOOKING.submit()` в `js/main.js`: дизайн менять не нужно.

## Язык

Автоматически по языку браузера (ru / en / es, остальные → es), выбор запоминается. Прямые ссылки: `/#ru`, `/#en`, `/#es`.

## Локальный просмотр

```
cd site && python3 -m http.server 8000
```
